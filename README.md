## About the Project

This assignment focuses on building a front-end application that combines information from two different APIs to create something useful for a veterinary practice.

The idea is to use data returned from one API to make a request to another API, then bring that information together in a way that helps veterinary staff.

The goal is to get more comfortable working with multiple APIs and understanding how different services can communicate with each other.

## Project Goals

- Identify a problem that a veterinary practice could solve using API data.
- Retrieve information from an external API.
- Use that information to make a request to a second API.
- Combine the responses into something useful.
- Display the information in a clear, organized interface.

## Planned Tech Stack

- HTML5
- CSS3
- JavaScript
- Fetch API
- Two external APIs (to be selected)

## How It Would Work

1. The application sends a request to the first API.
2. JavaScript processes the returned information.
3. Data from the first response is used to make a request to a second API.
4. The application combines the information from both sources.
5. The results are displayed on the webpage.

## Concepts to Practice

- Working with multiple APIs.
- Making asynchronous requests using `fetch()`.
- Understanding JSON responses.
- Working with arrays and objects.
- Using data from one API to request information from another.
- Displaying information with DOM manipulation.
- Handling errors and missing data.
